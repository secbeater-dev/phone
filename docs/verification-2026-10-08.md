# 2026-10-08 新網路格式、大量多門號與用戶卡片驗證

基準：`6756f09`。發布版本：`20261008-network-location-v1`。

## 變更

- 台哥大中文網路 XML／XLSX、原始明細展開 XLSX；依來源 XML＋原始紀錄序號還原，摘要表明確拒絕。
- 基地台時間優先、internet 時間備援，保留兩時鐘／秒數／實際來源及逐門號 `subjects`。
- 多門號位置獨立 Worker／IndexedDB、資料夾選取、部分失敗及原資料保護、位置事件與視窗計數落盤、結果與來源有界分頁。
- 兩頁的整批門號卡片、搜尋、20 張分頁、欄位衝突與來源分頁；一般匯入維持時間分布圖首頁。

## 驗證方式

解析器先建立失敗合成測試，修正後驗證新 XML／XLSX、重複標題／多工作表、展開去重、兩時鐘與 JSON 往返、合法空報表及門號關聯。審查再補上同工作表空查詢先於另一查詢、CSP record 覆寫門號兩個回歸。

持久化引擎以既有小資料純函式為基準比較，檢查 30 分鐘端點、跨區、密集事件、完整明細／門號分頁、排除、取消與清理。瀏覽器使用合成多檔合計超過 16 MiB、卡片搜尋／分頁、部分失敗、配額與取消保留、一般資料獨立及新格式 JSON 往返。

私密 opt-in `tests/browser/private-network.test.js` 僅允許本機來源；逐檔解析指定資料夾，再使用資料夾控制項完整匯入 XML。無檔名、內容、筆數、截圖或衍生資料輸出；僅記錄階段 PASS／FAIL，原始來源唯讀。正式站僅使用合成資料。

## 執行結果

- `npm ci`：依鎖定版本安裝成功，0 個已知套件漏洞。
- `npm test`：85 項通過、2 項私密 opt-in 略過，0 失敗。
- Chromium Headless Shell `npm run test:browser`：19 項通過、7 項 opt-in 略過，0 失敗。新回歸包含首次查詢失敗及首次列表讀取期間取消，確認保留舊批次；合計 18 MiB 合成 JSON、摘要檔提示與時間來源 JSON 往返通過。
- Edge 既有大型合成測試：10 萬／20 萬筆一般匯入通過，首次時間圖及列表正確；量測約 27／86 秒，最大 UI 計時延遲 171／165 毫秒，匯出取消約 146 毫秒。
- Edge 新增 10 萬筆密集位置事件測試通過：四份合成 JSON 匯入、單一最大視窗、完整明細讀取及第二頁均正確，每頁 500 筆。匯入至讀取第二頁共約 134 秒；最大 UI 計時延遲約 1,692 毫秒。
- 上述效能測試部分與其他驗證同時執行，數字只代表這次本機環境，包含測試工具傳送合成檔案的成本；不代表所有瀏覽器／硬體均有相同速度或延遲。
- 私密資料夾逐檔解析與完整 XML 資料夾匯入階段均通過；首次驗證發現畫面完成訊息早於首次查詢，已修正採用邊界並加入失敗／取消回歸。最終引擎版本的逐檔解析、整批匯入、門號卡片及同源 GET 複驗均 PASS，只記錄階段結果。

## 發布驗收

最終程式審查的發現均已修正並通過複審，包含舊 JSON 合併欄位多門號不可串成不存在的門號；無法歸屬的合併姓名等資訊另存為未辨識，不錯配給個別門號。

此版本沿用 GitHub Pages 發布；正式站只用合成資料，核對版本、24 個程式／樣式／圖片資產 SHA-256、7 個入口 SRI 及 CSP，並重新執行瀏覽器回歸。實際提交、部署連結與發布後驗收狀態另記本機更新日誌。
