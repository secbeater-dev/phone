# Repository maintenance instructions

1. Before modifying any repository file, read `fullview.md` completely.
2. After changing architecture, interfaces, parsers, UI, persistence, privacy controls, tests, or deployment, update `fullview.md` and its change log.
3. Never copy, stage, commit, upload, log, screenshot, or document real CDR data or derived identifiers. Use synthetic fixtures only.
4. Keep private source files outside this repository and stage intended files explicitly.
